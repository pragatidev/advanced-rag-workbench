# How this course works

Every technique is three moves:

1. A picture (this card, or an animation).
2. Lab parts under `labs/{lab_id}/part_k/` you can resume a week later.
3. One full run that prints a delta. Keep the technique only when the metrics file pays for it.

The workbench is one `rag/` package. Labs import it. They do not copy pipelines.

`starter/` has TODOs. `part_k/` is complete. `solution/` is the reference. A `# %%` twin lives under `notebooks/`.
