# Adaptive routing: none, single, multi, source

Mixed traffic is not one pipeline.

- none: greeting. Do not retrieve.
- single: one local question. Dense or hybrid once.
- multi: a theme or comparison. Several retrieves or a graph.
- source: an error code or a named doc. Search that collection only.

Jeong et al. NAACL 2024 trained a classifier. We ship a transparent router in `rag/query/router.py`.
