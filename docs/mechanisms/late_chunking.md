# Late chunking

Late chunking runs a long-context encoder over the document first. Then it mean-pools the already-contextual token vectors inside each chunk span.

The chunk vector remembers the document. That is the claim.

This lab uses a HashEmbedder stand-in of that shape. A production swap is a long-context encoder. On this small corpus the board often says the extra cost does not pay. That is a valid refuse.
