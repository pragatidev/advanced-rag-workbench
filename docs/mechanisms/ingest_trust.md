# Ingest trust is the other half

Treat retrieved text as data is the generate half. Ingest trust is the other half.

PoisonedRAG: five malicious texts per target in a million-scale store, 90 percent attack success. USENIX Security 2025, pages 3827-3844.

EchoLeak CVE-2025-32711 is production retrieval-injection. CVSS 9.3.

The allow-list is who may enter the index. The planted-doc canary fails if an untrusted chunk wins retrieve. This clone does not reconstruct the attack.
