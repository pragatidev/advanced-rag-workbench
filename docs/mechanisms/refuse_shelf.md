# What this course did not teach

The refuse is the point. You can name the paper and still not ship it.

## Training

- A trained Self-RAG model (we shipped the prompt loop and said so).
- RAFT. Fine-tune the generator on gold docs plus distractors. No fine-tune lab.
- RankRAG. Instruction-tune one model to rank and generate. Training.
- RAG-R1. An RL search policy. Not a prompt lab.

## Extra stacks

- Speculative RAG. A small specialist drafts. A larger generalist verifies. Two-model serving.
- LumberChunker. An LLM picks narrative cuts. Cost on a large corpus.
- KAG install. Typed indexes are a card. No OpenSPG install.
- A Microsoft GraphRAG index (we shipped a seeded tiny graph).
- Mem0, Neo4j, or turbopuffer install. Named. Not installed.
- LangChain as the package identity (one `rag/` library).

## GPU, crypto, code bench

- ColPali GPU. Page as image. Caption as text is Monday.
- C-FedRAG TEE. Retrieve and generate in an enclave. No TEE lab.
- FRAG HE. Homomorphic nearest neighbor. Extra threat model.
- SWE-bench. Course identity is enterprise documents.

## Policy and Course 2

- Web CRAG (the door stays locked). Always-on web is off.
- Multi-agent planners. Course 2 is Agentic Architecture. This course kept one retrieve-as-tool loop.
