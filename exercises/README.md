# Coding exercises

Udemy starters. Fill the TODOs. References are under `solutions/`.

Run one from the repo root, for example `python exercises/ex_orphan.py`. Until you fill its TODO it stops with `NotImplementedError`; `python solutions/ex_orphan.py` shows what a finished one prints.

- `ex_orphan.py` find the 3 percent chunk that lost ACME
- `ex_rrf.py` Reciprocal Rank Fusion with k=60
