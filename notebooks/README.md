# Notebooks

Optional twin of the labs. Open in VS Code or Jupyter. No extra pip package is required to *read* the notebook. To run cells you need a kernel (VS Code Python + Jupyter extension, or `pip install jupyter`).

`02_naive_pipeline.ipynb` is the same six stages as `labs/02_naive_pipeline.py`. Prefer the `.py` lab if you want one file that also runs as `python labs/02_naive_pipeline.py`.
